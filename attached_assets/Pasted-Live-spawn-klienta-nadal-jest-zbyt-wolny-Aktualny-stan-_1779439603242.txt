Zrób audyt i naprawę w dwóch miejscach.

A) SQL tick_customer_orders:

2. Jeśli tak, sprawdź czy SELECT do v_orders filtruje poprawnie aktywne/nieaktywne zamówienia.
3. Zmień SELECT v_orders tak, żeby zwracał tylko aktywne zamówienia:
   WHERE user_id = p_user_id AND expires_at > v_now
4. Upewnij się, że SELECT v_orders jest po pętli spawn_customer_order i po UPDATE last_customer_spawn_at.
5. Dodaj w zwracanym JSON:
   - spawned
   - active
   - max
   - next_spawn_at
   - orders
   - order_count = jsonb_array_length(v_orders)
6. Przygotuj SQL:
   attached_assets/sql_fix_tick_customer_orders_return_fresh_orders_v1.sql
