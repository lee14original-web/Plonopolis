Wymagania A — live timer nowego klienta:
1. W oknie Lady pokazuj realne odliczanie:
   "Nowy klient za: 3s", "2s", "1s".
2. Gdy licznik dojdzie do 0 i aktywnych klientów jest mniej niż limit:
   - automatycznie spróbuj pobrać/spawnować nowego klienta,
   - odśwież customerOrders,
   - nie wymagaj zamykania/otwierania okna.
3. Usuń tekst "odśwież listę", bo nie ma takiego przycisku.
4. Jeśli lista klientów jest pełna:
   - pokaż "Limit klientów osiągnięty" albo ukryj timer.
5. Zabezpiecz przed spamowaniem RPC:
   - użyj ref/flag typu isSpawningCustomerRef,
   - przy nextIn <= 0 wywołuj spawn/refresh tylko raz,
   - potem resetuj po zakończeniu loadCustomerOrders.
6. Jeśli istnieje już funkcja typu loadCustomerOrders / ensureCustomerOrders / spawnCustomerOrder, użyj jej zamiast tworzyć nową logikę.

Wymagania B — animacja nowego klienta:

   - zielona/złota poświata,
   - delikatna animacja fade/scale,

Wymagania C — ostrzeżenie, że klient zaraz zrezygnuje:
1. Dla każdego klienta policz procent wykorzystanego czasu:
   elapsed / totalDuration.
2. Jeśli wykorzystano >= 75% czasu albo zostało <= 25% czasu:
   - karta dostaje ostrzegawczy styl,
   - czerwona/pomarańczowa migająca obwódka,
   - pokaż czerwone "!" lub "⚠" w rogu karty,
   - czas do końca pokaż w ostrzegawczym kolorze.
3. Jeśli klient ma >= 90% wykorzystanego czasu, ostrzeżenie może być mocniejsze.
4. W widoku szczegółów klienta też pokaż komunikat:
   "Uwaga: klient niedługo zrezygnuje!"
   jeśli spełnia warunek ostrzeżenia.
